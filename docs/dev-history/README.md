## 0.1.1 之前的一次性数据迁移

会话级模式在 0.1.1 被移除。为避免"旧会话 `mode=strict` 且钉子没有 `level`"这一语义丢失，
在改代码**之前**先在本机 `~/.dsh/storages/highlightpin.json` 上做过一次一次性迁移（脚本未提交进仓库）：

- 检查了 **3 个会话、共 4 枚钉子**。
- **1 个会话**带 `mode: 'strict'`：其中的钉子已有显式 `level`，因此只删除了 `mode` 字段。
- **1 个会话的 2 枚钉子**缺少 `level`，且该会话没有 `mode`：按要求写为 `'pin'`。
- 迁移后：全部会话不再有 `mode`，全部钉子都有 `level`。
- 迁移前的文件已备份到 `~/.dsh/highlightpin-backup-<时间戳>.json`。

迁移完成后，代码侧只剩一条规则：有效级别就是 `pin.level ?? 'pin'`。
